# mygamee
GAME PROPOSAL
Game Title
Highway Rush – Traffic Racer

Main Goal
The player's goal is to drive a car along a busy highway, avoid collisions with other vehicles, and survive for as long as possible while achieving the highest score possible.

Player Controls
⬅️ Left Arrow: Move the player's car left.

➡️ Right Arrow: Move the player's car right.

Gameplay
The game takes place on a realistic-looking 2D highway viewed from above.

The player controls a car that drives along the highway.

Other vehicles appear on the road and act as obstacles.

The player must steer left and right to avoid collisions.

Traffic gradually moves faster as the game progresses, increasing the difficulty.

Scoring
Players earn points based on the distance they travel.

The longer the player survives, the higher their score becomes.

The current score is displayed during gameplay.

Win/Lose Rules
The player starts with 3 lives.

Each collision with another vehicle removes 1 life.

When all 3 lives are lost, the game ends.

There is no fixed winning point. The objective is to survive as long as possible and achieve the highest score.

After losing, a Game Over screen displays the final score and a Play Again button.

First Version
The first version will include:

A Start Screen with the game title and Start Game button.

A realistic 2D highway environment.

A player-controlled car.

Traffic vehicles that act as obstacles.

Left and right arrow-key controls.

Distance-based scoring.

A three-life system.

Increasing traffic speed as gameplay progresses.

Collision detection.

A Game Over screen with the final score and Play Again button.

Technical Requirements:

HTML for the game structure.

CSS for styling and visual design.

JavaScript for movement, controls, scoring, collisions, and game logic.

No backend, database, Python server, paid services, login system, or secret API keys.

Hosted as a static website using GitHub Pages.
